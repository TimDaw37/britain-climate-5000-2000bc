# Publish the graphs

1. Open https://github.com/TimDaw37/britain-climate-5000-2000bc/settings/pages
2. Under Build and deployment, set Source to **Deploy from a branch**.
3. Branch: **main**, folder: **/ (root)**.
4. Save. After a minute the site is at:
   https://timdaw37.github.io/britain-climate-5000-2000bc/

`index.html` and `data/bundle.js` must both be on `main`. If they are missing from the repo, copy them from the project folder `britain-climate-site/`.
